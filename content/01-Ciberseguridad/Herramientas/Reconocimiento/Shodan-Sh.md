**Categoría:** Reconnaissance

**Descripción:**

Shodan es un motor de búsqueda diseñado para encontrar dispositivos conectados a Internet. A diferencia de los motores de búsqueda tradicionales como Google, que indexan contenido web, Shodan indexa banners de servicios y metadatos expuestos por dispositivos accesibles públicamente, tales como cámaras IP, routers, servidores, sistemas SCADA, dispositivos IoT, etc.

Es una herramienta utilizada comúnmente en ciberseguridad para:

- Identificar servicios expuestos y puertos abiertos.
- Detectar vulnerabilidades conocidas en sistemas detectados.
- Realizar auditorías externas sobre la superficie de exposición de una organización.
- Analizar la seguridad de dispositivos IoT.

Shodan ofrece tanto una interfaz web como una API que permite realizar búsquedas automatizadas y generar informes. También es posible filtrar por geolocalización, sistema operativo, organización, y mucho más.
